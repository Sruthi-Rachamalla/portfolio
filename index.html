BLOCKCHAIN · WEB APPLICATION

A Framework for Crypto-Based Monetization of Driver Behavior with Blockchain

Developed a blockchain-based web application designed to incentivize safe driving. Built with HTML5, CSS3, and vanilla JavaScript, it connects to a DataHub API to calculate driving scores, rankings, and earnings.

Integrated MetaMask so users can redeem earned tokens for parking, fuel, and toll payments. A daily feed provides real-time feedback on driving behavior.
